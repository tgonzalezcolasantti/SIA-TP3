# Datos del enunciado

Los archivos entregados con el enunciado se guardan directamente en esta carpeta:

- `fraud_dataset.csv` y `fraud_dataset_documentation.pdf`: ejercicio 1.
- `digits.csv` y `digits_test.csv`: ejercicio 2.
- `more_digits.csv`: ejercicio 3.
- `digit_dataset_loader.py`: cargador provisto con los datos.

El ejercicio 1 lee `data/fraud_dataset.csv` directamente. Los CSV se ignoran en
Git por su tamaño. El PDF se versiona porque documenta las columnas y la
restricción de uso de `flagged_fraud` para el entrenamiento.
